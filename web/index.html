رسائل تنتقل عبر الضوء.

LightLink مشروع تجريبي مفتوح المصدر لاستكشاف إرسال رسائل نصية قصيرة بين هاتفين باستخدام ومضات الفلاش والكاميرا، دون نقل محتوى الرسالة عبر الإنترنت.

نسخة تجريبية — غير معتمدة بعد

ما الذي يتضمنه النموذج الأولي؟

  • إطار بيانات يتضمن علامة بداية وطول الرسالة وبيانات UTF-8 وفحص CRC.
  • إرسال تجريبي للبتات عبر فلاش الهاتف المتوافق.
  • استقبال تجريبي عبر تحليل سطوع صورة الكاميرا.

تنبيه: لم يتم التحقق من موثوقية الاتصال على هاتفين فعليين. قد يفشل فك الرسائل بسبب توقيت الكاميرا أو التعريض التلقائي أو الإضاءة المحيطة. لا تستخدمه لنقل بيانات حساسة.

البناء

يمكن تنزيل ملف APK التجريبي من قسم Artifacts في تشغيل GitHub Actions الناجح. هذه الصفحة تعريفية فقط؛ لا تستخدم الكاميرا أو الفلاش.

الاتصال بالضوء ليس تشفيرًا، وCRC لا يثبت هوية المرسل.
