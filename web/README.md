# LightLink Vercel companion page

This is an informational landing page only. It does not access camera/flash hardware and does not transmit messages.

## Deploy from a phone
1. Import this GitHub repository into Vercel.
2. Set **Root Directory** to `web`.
3. Select the **Other** framework preset and leave the build command empty.
4. Deploy. Vercel serves `web/index.html`.

The Android app is built separately by GitHub Actions. Vercel does not build the APK.
